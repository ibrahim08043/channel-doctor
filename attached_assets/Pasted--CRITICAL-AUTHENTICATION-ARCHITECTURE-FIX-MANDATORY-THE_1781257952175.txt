NO connection button should appear.

REMOVE ALL OF THIS.

## 2. CONNECTED CHANNEL SYSTEM

This must ONLY work through GOOGLE OAUTH AUTHORIZATION.

The ONLY way to connect a personal YouTube channel is:

Login with Google →
Authorize YouTube access →
Fetch the authenticated user's channel from Google APIs →
Automatically detect their real YouTube channel.

The user should NEVER manually connect a channel.

The user should NEVER click "Connect this channel".

The user should NEVER select an analyzed channel as their own.

The connected channel MUST come directly from Google's OAuth identity.
